# 치바쿠지 마진 계산기

React + TypeScript 기반 단일 페이지 계산기입니다. 서버, DB, 외부 API 없이 브라우저에서 계산하고 localStorage에 입력값을 저장합니다.

## 실행

```sh
npm install
npm run dev
npm test
npm run build
```

`dist` 폴더를 정적 웹 호스팅에 배포할 수 있습니다.

## 계산 기준

중간 계산은 반올림하지 않고 화면에 표시할 때 금액을 원 단위, 마진율을 소수점 둘째 자리로 반올림합니다. 수입부가세와 수수료 부가세는 납부액과 원가 반영액을 구분합니다. 추가 배송·통관 비용, 한국 포장·배송 비용 및 기타 비용은 전체 구매·판매의 총액입니다. 과세가격 직접 입력 역시 전체 구매 기준 총액입니다.

업체 안내에 따라 기본 수수료율은 6.4%에 부가세 별도(10%)이며 수수료 매입세액 공제는 미반영입니다. 실제 수수료 지급액은 총매출의 7.04%입니다. 수입부가세는 전액 공제합니다. 기본 조건에서 총매출 1,280,000원, 공급가액 약 1,163,636원, 수수료 지급액 90,112원, 영업이익 약 330,341원, 마진율 약 28.39%입니다. 기존 저장 설정은 최초 1회 수수료 부가세 별도로 전환하고 이후 사용자의 변경을 유지합니다.

최초 요청의 부가세 포함·수수료 공제 미반영 조건에서는 영업이익 약 338,533원, 마진율 약 29.09%입니다. 판매가격은 슬라이더에서 10,000~19,000원 사이 500원 단위로 조절합니다. 업체가 안내한 정산일은 익월 20일이며 영업이익 산식에는 영향을 주지 않습니다.

실제 통관 조건에 따라 달라지는 추정치이며 일본 소득세·주민세는 제외합니다.
